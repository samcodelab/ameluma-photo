# Framepebble resources

AppIcon contains an original code-generated blue/violet pebble mark. Reproduce it with `swift tools/generate_icon.swift /absolute/path/to/Framepebble`. It uses Apple Core Graphics/ImageIO and contains no third-party artwork. The iOS 1024-pixel asset is opaque; Mac assets provide native sizes and alpha. Final brand/Store presentation approval remains release work.

PrivacyInfo.xcprivacy applies to both native targets. It declares no tracking or collected data and required file-timestamp access for local app-owned/user-authorised files. Review the signed archive's privacy report before distribution.
