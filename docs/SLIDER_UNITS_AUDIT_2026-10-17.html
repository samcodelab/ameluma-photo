Slider units audit — 17 October 2026

Reviewed slider call sites across SharedUI and platform apps. Units follow familiar professional conventions. Competitors do not have a single universal numerical range. Display mappings preserve Ameluma's existing recipes and saved values; matching labels does not imply identical effects.

Control familyPresentation and behavior
Retouch brushPixels on the full edited output canvas, not display points or preview pixels. 1 px minimum; maximum 5,000 px or 40% of the shorter canvas edge, whichever is smaller. Square-root slider travel improves small-size precision. Brackets change size by approximately 10%, at least 1 px. Immediate centred canvas footprint during slider or numeric entry; persists briefly after changing size, scales with zoom.
Hardness / opacity0–100%, editable numerical values, 1% slider steps. Existing normalized storage retained.
ExposureEV, existing −2 to +2 EV range, 0.01 EV increments. No undocumented renderer change.
Brightness / contrast / saturation−100 to +100, neutral 0. Presentation-only mapping of established parameters.
Highlights / shadowsHighlights −100 to 0 (recovery); shadows 0 to 100 (lifting). Current engine has one-directional controls; a symmetric range would require new processing behavior.
Warmth / tint / vibranceRelative −100 to +100, neutral 0. Warmth is not calibrated temperature; never label it Kelvin.
Colour MixHue in degrees, −60 to +60; saturation/lightness −100 to +100. Numerical input and whole display-unit slider increments.
Creative filters / replacement / masksStrength and intensity in percent. Replacement feather remains a percentage of edited shorter edge, not a fabricated radius.
Crop / GIF / collage zoomPercent (100% = base framing), consistent with existing crop precision controls. GIF speed remains a playback multiplier; duration remains seconds.
Rotation / straightenDegrees, including explicit degree labels on straighten; existing bounds retained.
AnnotationsStroke width in output pixels, opacity in percent. Transform coordinates stay explicitly labelled normalized percentages.
WatermarkOpacity, relative width and margin in percent; rotation in degrees. Relative sizing deliberately follows the existing resolution-independent watermark contract.
Collage layoutSpacing, borders and corners retain proportional percentages because cells can differ in size. Freeform geometry now has visible percentage readouts; rotation has degrees.
Output qualityPercent, rounded readouts. Compression target stays KB. Gallery thumbnail size is a display-size control, not image resolution.

Primary references

  • Affinity Photo: brush width in pixels; opacity and hardness percentages; numeric entry
  • Photoshop: brush cursor and painting options
  • Pixelmator Pro: exposure in EV

Verification boundaries

Automated tests cover reversible display mappings, existing rendering behavior, and newly accepted small retouch dabs. Native Mac and iOS builds are checked separately. This audit does not claim physical-device usability or pixel-perfect equivalence with competitor algorithms. Existing source bytes and normalized edit records are retained.
