# Distribution preparation

Framepebble intends a one-time universal purchase at a target A$29.99. No store application, price, subscription, IAP, agreement acceptance or submission was performed.

Release targets now use `com.broadframestudio.framepebble` on both platforms. Debug retains `com.broadframestudio.framepebble.ios` for the mobile development container and the established Mac identifier. Apple requires related platforms to share the bundle ID/app record for [universal purchase](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-platforms). Configure an authorised team and one shared record before archives; Debug-to-Release data migration and signed installation must be verified. Do not register records without approval.

The Mac target has App Sandbox/user-selected read-write entitlements. Automations create security-scoped bookmarks for explicit folder selections. Photos imports use PhotosPicker; saving requests additions only and has a purpose string. No full Photos read access, telemetry, account or third-party SDK exists. Mac uses the outgoing-network client entitlement solely to acquire explicitly dropped HTTPS image links when browser image bytes are unavailable; there is no upload service or networking in Core. PrivacyInfo.xcprivacy is included in both app bundles, declares no tracking/collected data, and documents file-timestamp access for app-container/user-authorised source/index/cache/automation operations using C617.1 and 3B52.1. Audit a signed archive's privacy report and current [required-reason definitions](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons) before submission.

[Sensitive Content Analysis](https://developer.apple.com/documentation/sensitivecontentanalysis) is available within these OS targets, but requires `com.apple.developer.sensitivecontentanalysis.client` in a signed app. Apple's [integration guidance](https://developer.apple.com/documentation/SensitiveContentAnalysis/detecting-nudity-in-media-and-providing-intervention-options) states paid-program members can add the capability after the applicable agreement is signed; analysis also depends on user/system policy. This workspace has no configured signing team/entitled build. The photo-utility pre-share use case and applicable terms need a developer distribution review; this implementation uses manual review and does not fabricate results. No sensitive entitlement was enabled or agreement accepted.

Original code-generated icon assets are included and compiled for both targets. Outstanding: final brand/icon approval; device/minimum-OS signing/archives; actual sandbox/bookmark/revocation/provider QA; privacy/support text review; App Store data declarations; accessibility/localization; export-compliance/encryption questionnaire; screenshots/marketing matching completed behavior; Standard EULA. CryptoKit is used for SHA-256 duplicate hashes, not an encrypted vault. Do not infer that framework usage alone settles export-compliance declarations.

Optional login support was verified against Apple’s [SMAppService documentation](https://developer.apple.com/documentation/servicemanagement/smappservice): use ServiceManagement's SMAppService for a user-enabled main-app login item rather than a privileged daemon. No login item has been registered and no working toggle is advertised. Monitoring currently lasts only while Framepebble remains open.
