# Hide Something editing contract

Hide Something opens the privacy-flagged gallery, rather than unexpectedly editing whichever image happened to be selected. The photo context menu provides Edit Hide Something (Reveal & Edit for flagged photos). Existing manual and actual Apple findings are used; no detection result is invented. Automatic detection remains capability/policy gated.

The shared OverlayEditingSession captures one photo’s full starting configuration and keeps a private draft. It reuses EditingHistory and groups drag/slider updates into single undo steps. Preview rendering uses the normal Core renderer with the draft. Autosave, gallery edits and exports do not see that draft. Cancel, Escape and Close Editor discard it. On Mac and regular-width iPad the editor occupies the main workspace; iPhone uses a full-screen editor. The draft is held outside the persistent project so adaptive presentation can retain it. Apply/Cancel is explicit. Previously applied edits remain intact.

Apply first requires a rendered, validated current preview, verifies the photo still exists and has not changed concurrently, then makes one global history commit. Existing dimension overrides are retained. The resulting project still supports normal Undo/Redo. Apply & Crop is an explicitly named apply action and queues precision editing until the privacy editor has closed.

Draw and Select are distinct tools. Drawing an area immediately selects it for moving, resizing and rotation. Clicking empty photo space deselects it and returns to Draw for the next area. Select lets users choose areas, move their bodies, scale with eight resize handles, rotate by dragging the rotation handle, or delete using the toolbar/context menu. Optional numeric fields in the collapsed Precise Transform section provide accessible precision alternatives; geometric sliders are removed. The inspector can be hidden. OverlayGeometry performs normalized, rotation-aware resizing and pointer-angle rotation shared across platforms and clamps invalid/extreme bounds. An accessibility action can create a centred area. The selected effect/shape controls edit the selected area, rather than silently changing only defaults for a future area. Delete removes only the selected draft area and is reversible. Mask rendering, geometry and export remain shared; originals are never changed.

Verified by automated Core and workspace tests plus real Mac UI interaction on synthetic fixtures: flagged filtering; context-menu entry; drawing Pixelate and Frosted areas; selected effect changes; Delete/Undo/Redo; Command-Z; moving and undoing a move in one step; Escape followed by reopening with zero masks; continuous Draw, Select, corner-handle scaling and Close Editor cancellation; direct rotation to 56.2 degrees and native Command-Z restoration to zero; keyboard Delete and Command-Z restoration; Apply and global Undo/Redo. iOS builds and app-host regression tests exercise the same models; physical-device touch interactions remain unverified. Native Mac UI automation was available for this fix, unlike the preceding review.

The embedded workspace now uses a left Select/Draw and Privacy/Annotation tool rail, central canvas and contextual right inspector. A separate Objects list selects or deletes masks and annotations. Only the selected object exposes its properties, avoiding a growing form for large numbers of edits. iPhone retains compact tool selection and the same Objects list. Verified live Mac tool switching and object-list selection.

Reviewed workspace follow-up: Mac library navigation is hidden during editing to reclaim canvas space. Embedded Mac/iPad canvas supports bounded zoom, scroll-to-pan and Fit; all interaction coordinates remain relative to the displayed output. Live synthetic Mac checks verified zoom to 125%, handle resizing at that scale, Command-Z, Fit and drawing a second area inside the scrollable canvas. Apply & Crop is labelled explicitly. Privacy guidance is a disclosure rather than permanent inspector text. Selection properties no longer offer a next-annotation type selector.

Drawing now immediately selects the new mask or annotation. Clicking the selected area keeps it selected; clicking empty photo space clears selection and returns to drawing without creating an extra object. The next drawing keeps the last selected effect/shape or annotation kind. Verified with live Mac synthetic-image interaction.
